This guide is written to be read by **both a human and an LLM/agent**. If you feed this file to an agent along with a 1.x command, the [Agent Rules](#7-agent-rules-1x--2x-command-translation) section is enough to emit the correct 2.x command.

## 0. Did this plugin exist in 1.x?

**Yes — as a standalone plugin, not in the v1 monorepo.**
- It is **not** present in the `contentstack/cli` monorepo at `v1.59.0` (nor at the monorepo's current `core@v1.64.0` line) — no `contentstack-content-type` package and no `content-type:*` command exists there.
- It ships from the **`contentstack/cli-plugins`** repo. `origin/main` carries the v1 line at version **`1.5.1`**; `origin/v2-dev` carries **`2.0.0-beta.1`**.
- Therefore this is a **real 1.x → 2.x migration** (flag diff below), not a brand-new 2.x plugin.

## 7. Agent rules: 1.x → 2.x command translation

Apply in order and output the 2.x equivalent:

1. **Command id:** leave all six `content-type:*` ids unchanged.
2. **Auth flag renames (value-preserving):**
   - `--stack` | `-s`  → `--stack-api-key` (note: v1 `--stack` was a *Stack UID*; in practice pass the Stack API key)
   - `--token-alias`   → `--alias`
3. **Short-char expansions (all removed except `-k`, `-a`):**
   - `-c` → `--content-type`
   - `-l` → `--left`, `-r` → `--right` (compare)
   - `-o` → `--origin-stack`, `-r` → `--remote-stack` (compare-remote)
   - `-p` → `--path` (details; `--no-path` to hide)
   - `-o` → `--output`, `-d` → `--direction`, `-t` → `--type` (diagram)
   - `-o` → `--order` (list)
4. **`compare-remote` auth:** never add `--alias`/`--stack-api-key`; auth is derived from `--origin-stack`.
5. **Enum validation:** `--direction` ∈ {portrait, landscape}; `--type` ∈ {svg, dot}; `--order` ∈ {title, modified}. Flag out-of-enum values as errors.
6. **Never invent flags.** If a 1.x flag isn't in this guide, keep it and note it's unverified.

**Worked example**
Input: `csdx content-type:diagram -a mytoken -o model.svg -d landscape -t svg`
Output: `csdx content-type:diagram --alias mytoken --output model.svg --direction landscape --type svg`
