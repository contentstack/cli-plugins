# Doc / README Accuracy — `@contentstack/cli-cm-export`

Internal fix-list (not customer-facing). Tracks inaccuracies in the v2 README and the official doc-site pages for the export command, verified against code (`cli-plugins @ v2-dev`, `cli @ v1.59.0`).

> **Root cause / where to fix:** the v2 `README.md` is generated by `oclif readme` (run from the package `version` script). Editing `README.md` by hand is overwritten on the next version bump — **fix the flag descriptions / examples in `src/commands/cm/stacks/export.ts`** instead. Decide the README-autogeneration strategy before hand-editing.

---
